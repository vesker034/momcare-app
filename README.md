# MomCare

Учебный MVP кроссплатформенного приложения для поддержки беременных: календарь по неделям, дневник самочувствия, визиты к врачу и полезные материалы.

**Стек:** React Native, Expo, TypeScript, Node.js, Express, Prisma, PostgreSQL, Docker Compose.

Приложение носит информационный характер и не заменяет консультацию врача.
